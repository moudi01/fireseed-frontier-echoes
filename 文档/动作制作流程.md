# 角色动作制作

1. 在还原后的素材库打开 `动画/主用模型.md`，选对应角色的 Blender 主工程。已有 24 动作库、专属技能和协同场景分别维护。备用模型和装备的位置见同一素材库根目录的 `备用成品索引.md`。
2. 为新动作另存工程，确定动作名、帧率、起止姿态、持械侧、握点、武器轴和触发帧。复用已有姿势时，依目标角色的肩宽、骨长和骨轴调整肩、肘、腕与骨盆。弓弦、箭、灯和绳等装备单独设置跟随。
3. 在 Blender 的 Action Editor 中保留可编辑关键帧，让曲线完成中间插值。检查循环接缝、脚掌接地、装备接触和动作事件。用实际棋盘正交镜头检查轮廓及预警可读性。
4. 导出 GLB 时带上模型、骨架、材质和需要的动作。从空白工程重新导入导出物，核对动作名、帧范围、材质和绑定。可编辑工程与引擎交付文件分别保留。

新建角色的批处理入口在 `_tools/美术/`。用 Blender 后台模式运行脚本，参数置于 `--` 之后。`prepare_character_batch.py` 接收输入与输出目录，`bind_character_batch.py` 从准备好的模型建立工程骨架，`animate_character_batch.py` 接收输入、输出和提供动作的 donor 文件。输出使用新的目录，便于与原件对照。当前角色可直接用恢复的主工程编辑；如需从外部游戏采集新的参考动作，需另备有权使用的参考库。
