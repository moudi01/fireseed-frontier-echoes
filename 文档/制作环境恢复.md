# 在新电脑恢复制作环境

在 Windows 上克隆源码，并从项目云盘逐个下载全部 ZIP 到同一个目录。保留 ZIP 原文件名。示例把下载文件放在 `Downloads/fireseed`。[GitHub 仓库](https://github.com/moudi01/fireseed-frontier-echoes) · [项目云盘](https://drive.google.com/drive/folders/1svBmGyPUBnbe1KYU9o_DV8gVTlbXIBxW)

```powershell
git clone https://github.com/moudi01/fireseed-frontier-echoes.git
cd fireseed-frontier-echoes
.\_tools\restore_workflow.ps1 -PackagesFolder "$env:USERPROFILE\Downloads\fireseed"
.\原型\P06_首章\build_windows.ps1
.\原型\P06_首章\playtest.cmd --scene book-slot-swap
```

还原脚本支持 Windows PowerShell 5.1 及更高版本。它校验每个 ZIP 和每个文件的 SHA-256，已有同名文件如有不同会停止。整个过程可重复运行。加 `-VerifyOnly` 可只校验下载包。

**源码目录**接收 Godot、Blender、固定版 Python 运行时和游戏按项目路径读取的资源。**独立素材库**位于源码目录旁，默认名为 `fireseed-frontier-echoes-assets`。可用 `-AssetsFolder 'E:\FireseedArt'` 指定其他位置。脚本按原有相对路径还原纹理、缓冲区和授权文件。同一份音频或模型有多个交付位置时，根据清单从已校验文件生成副本。

| 文件名 | 用途 |
| --- | --- |
| workflow-01、workflow-02 | Godot 4.7.2、Windows 导出模板、嵌入式 Python 和 Blender 5.3 |
| workflow-03 至 workflow-06、workflow-08 | 主用动作工程、游戏模型、贴图与概念图、音频、38 个试玩起点 |
| reserve-01-blender | 可编辑的备用动作、角色和装备工程，以及备用成品索引 |
| reserve-02-models-01 至 03 | 三个独立 ZIP，包含备用模型、glTF 缓冲和配套授权 |
| reserve-03-textures-art | 备用贴图、设定图与配色方案 |

在素材库内打开 `备用成品索引.md` 浏览备用资产，打开 `动画/主用模型.md` 选择主用角色工程。Blender 位于源码的 `.toolchain/blender-5.3/blender.exe`。Godot 编辑器位于 `.toolchain/godot/editor/`，直接打开 `原型/P06_首章/project.godot`。如只核验或提取某个包，可通过 `-Package` 指定完整文件名。恢复所有来源和别名请执行上方完整命令。
