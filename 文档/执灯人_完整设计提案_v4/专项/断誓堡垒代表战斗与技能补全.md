# 断誓堡垒代表战斗与技能补全

SKILL-PAIR-1.0 · 2026-10-27 · 关卡设计及0.13接入记录。先补双方技能与应对关系，再接共用实现；0.13已完成选定范围、六场普通／精英对照及保存续战，见[实际验证记录](../../../原型/火种计划_远征灰盒/验证记录_v013.md)。此为0.13历史记录：当时M04稳媒、指挥英雄和装备词条未实现；稳媒现已在[0.37](../../../原型/火种计划_远征灰盒/验证记录_v037.md)补齐，CMD和词条参见设计包现行入口；下表的0.12栏保留接入前缺口，不能当作现行实现状态。

## 一、关卡目标

选取现有RG02断誓堡垒的普通战RG02-N03“钟声掩矛”与精英战RG02-E02“双钟换防阵”，均为CH2／原生TH2，不新增地区、敌种或强制战斗。普通战展示旧声锁定历史位置；可选精英把单格记录变为双格，并用既有短冲改变侧翼压力。玩家可以不打精英，不要求先抽到普通战才准入。

体验目标是让敌方预警和己方职业各有作用。玩家的可选应对包括分散／侧线布阵、预设避险、保留雾绊次数、有限治疗与主动撤退；不把“玩家一定带治疗、一定延咒”作为剧情或通关前提。

验收先看动作因果：同一旧声不追踪移动目标；有空格且动作允许的避险能离开；雾绊在正确窗口延后一次，晚到不能回溯；所有技能只消耗真实次数和动作。原普通12—24拍、精英18—32拍仅作后续观察目标，按每拍0.5秒对应6—12秒、9—16秒逻辑播放，不含准备和阅读；本轮不设或宣称玩家胜率、尝试次数、整区分钟数达标。

复用既有棋盘、预警格和文字操作入口，不需要美术或新界面。此组合无付费点。

自由书槽与方案先留空，四职业固定特性／核心按本轮补全后真实执行。可另将T03的M04换成M03，保持人数与Cost不变，观察穿障射击而不是同时强塞四佣兵进原首发。T02纯士兵用于确认基础应对仍存在；不规定纯士兵必胜，也不把雾术师设成通行钥匙。

### 4. 必须修正的反制时序

旧版：敌t拍起手，t+2释放；玩家单位最早t+1见到预警并起手，t+2施加控制。按同拍合法动作同时结算规则，这个控制赶不上，不能称为对预警的有效反应。

本轮设计：EN06-A与EL03-A统一改为3拍起手；其他数值保持。t+1起手雾绊、t+2生效，可将敌原t+3释放改为t+4。若雾绊直到t+2才起手，则不满足“严格早于原释放”条件，保留反制模式跳过。由此无需偷看本拍新预警，也无需给玩家免费即时控制。

这是本轮设计修订，旧稿原为两拍。0.13已由battle_skills覆盖EN06-A／EL03-A所有遭遇载荷并检查一致性；七份冻结JSON仍为旧值。新实算单独归0.13，旧灰盒及历史证据不冒称新版效果。

## 三、难度评估

普通战以两只有限次数钟螺分别保存自身历史；精英换成一只双钟螺，加入短冲侧翼压力，仍有限次数且没有额外动作。两场都有“看懂预警后仍可能因站位、动作占用或次数不足而吃伤”的情况，保留构筑与站位价值，不保证一个姿态自动免伤。

首次验证只需少量机制片段和两场真实战斗，不逐怪逐卡跑完整远征。必须观察：实际触发次数、起手／释放／延后／落空时间、有效治疗与溢出、可行动人数、预警内有无可行落脚点。若表现不符，先查实现是否遵守设计，再调整具体设计缺口；不根据旧0.12的胜败直接加药、降敌或增加善行奖励。

| 接入后必须看到的现象 | 通过边界 |
| --- | --- |
| 没有普攻历史的钟螺 | 跳过旧声，照常普攻／移动；不造历史、不扣旧声次数 |
| 双钟两次普攻落在同一格 | 只有一个锁格，不追溯第三条补满，不对同人双倍命中 |
| 锁格后目标移动或补位 | 原空格落空；后进入锁格的敌仍可受击；不追原人 |
| 两名术师针对同一旧声 | 最多延后一次；第二个已起手雾绊仍按原机会结算；弱点持续到实际释放 |
| 雾绊与旧声原释放同拍 | 旧声照常生效，不把晚到控制计为成功 |
| 药师起手后原人倒地／离开范围 | 不换人、不复起、不退款；自己仍占释放动作 |
| 短冲路径后来堵塞／进入浅水／受阻 | 按已锁路径真实截停或原地失败，无额外攻击与瞬移 |
| 起手中保存后重载 | 历史、锁格／路径、cast_id、次数、冷却、首次特性标记和预计释放拍一致 |

上述是机制验收条件，0.13已有受控检查及普通／精英六场实算，具体证据与未覆盖边界见验证记录；不展开全区域数值校准。M03验甲另以受控护盾检查，M04稳媒在0.13当时未实现，0.37另作代表验证；没有为演示向两组原敌阵额外塞怪。

## 四、奖励配置

沿用原出发时锁定奖励计划，不新增技能通关奖励。普通战只使用原预留的对应槽，候选RB-GEAR／RB-MAT2／RB-PLAN不代表三份全得；地区目标完成才结其原目标委托。精英胜利增量仍为8铜／2公共结晶，其余候选亦必须占原预留槽。战后反馈显示真实结果与待带回物资，安全归城按原规则入账；不能为了技能演示把委托提前兑为现场现金。

无逐怪独立掉落、不因旧声重复或精英的两格命中多发奖励。免费预览与重看片段没有收益。补给、事件回访和可选精英是否值得打，继续由玩家按本趟状态决定。

## 五、本轮核对与交接边界

设计阶段已核对两阵ID、单位组成、TH2预算5／9、棋盘引用及T03许可。实现阶段已用共用执行器验证新三拍反制窗口、原目标重验、有限机会和保存续战，162项回归通过；七份基础JSON保持原字节，灰盒升级0.13。普通／精英实算可完成，不能据此宣称所有怪物、四职业或英雄技能齐全，或战斗平衡已定。

0.14已接单一士兵指挥英雄受控代表，见[验证记录](../../../原型/火种计划_远征灰盒/验证记录_v014.md)；后续接双槽装备词条。当前实算还显示反制延后不自动改善战损、避险可能使总血量上升但有队员倒地，正式平衡需结合可行动人数判断。当前任务状态只维护在[总路线图](../../../开发总路线图_执行版.md)。
