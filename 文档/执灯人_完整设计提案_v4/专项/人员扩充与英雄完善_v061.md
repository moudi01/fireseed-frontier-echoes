# 人员扩充与英雄完善 · 0.61

日期：2026-10-29。实施版本：`TINDER-GREYBOX-0.61`。根据本轮“增加佣兵职业、增加英雄、完善英雄设计”的要求，佣兵由4类扩至8类，英雄由7位扩至10位。本轮包含可玩的职业／英雄、人物卡、面板成长、装备和技能书兼容，以及H05／H06技能设计细化。新面板为首版设计值，整体平衡尚未定稿。

运行实现以灰盒的 `roster_content.py`、`roster_skills.py`、`hero_refinements.py` 及对应战斗入口为准。冻结的66份校验JSON未改，正文表格同步运行覆盖层。已有H01—H07的基础面板和成长未改。

## 人员结构与取得

- 普通士兵3类、佣兵8类、英雄10位，共21类人类模板；薇拉伴兽另外计数。
- 佣兵仍是Cost2、1被动＋1主动，城镇每人16铜；新职业沿用招募随机面板、经验成长、两书槽、1武器＋1防具。
- 英雄仍是Cost3、1被动＋2主动；技能书不替换天生技能，战前可编排已装备主动。人数、出战预算、名册容量均未增加。
- 新周目应召从十位“尚未取得”的英雄中均匀选择，曾取得后失联／永久损失者不回池。章节里程碑仍只发6枚印，无法在同一正常周目保证集齐十位；没有保证抽到某位的新规则。
- 人物卡描述背景与关系；阅读人物卡不会取得角色、补写调查线索或发放奖励。新三位在实际应召后接入现有叙事记录。

## 新佣兵设计

面板与成长均按“生命 / 物攻 / 魔攻 / 治疗 / 物防 / 魔防”排列。成长为每升一级的固定增量；初始面板在闭区间内分别生成。

### M05 守缆卫 · 隔位护持的护运佣兵

- 定位：近场防护支援；从两格内为承压同伴补有限私盾。
- Lv1区间：42～52 / 5～8 / 0～0 / 0～2 / 12～16 / 7～11；每级：6 / 1 / 0 / 0 / 1 / 1。
- 普攻：物理，1格，间隔3拍；装备基底：EF06、EF07、EF08，各品质均适配。
- 来历：护运队里负责收紧护缆和扶住落后者的防护手，习惯隔着一段路把护片交到需要的人手里。职业称呼不代替每名受雇者自己的名字。
- 受雇动机：按约护送同行者走完这一趟，挣到一份清楚结算的工钱。
- 顾虑：护片递得太迟，或者把一次防护误说成能保住所有人的保证。
- 被动「余绳」：本场首次本人主动对另一名友军实际增加正数私盾后，自己在下拍起得4私盾、持续2拍；包括BK05等本人主动护持，不因无效刷新或派生护盾触发。
- 主动「隔位护持」：2格内另一名可见站立友军处于已锁危险或生命不高于60%时，给予12私盾、持续2拍。起手1拍，C4，每战2次；没有别人时不空放，只护原目标，不护本人、不治疗、不代受。
- 优势：不必与目标相邻也能护持。 先护他人再得到一次本人防护，适合站在队伍前侧。
- 局限：主动只有两次，不能长期覆盖整场。 普攻较慢，盾不恢复生命，也不能接回倒地者。
- 关系：与护运枪卫分清近处守路和隔位护持的职责。 接受莉安对伤势的核对，不把护盾当作治疗。

### M06 踏隙客 · 沿空隙走位的近战佣兵

- 定位：近战侧接与短距避险；先用一个主动换位置，再等待本人原有普攻。
- Lv1区间：32～42 / 10～13 / 0～1 / 0～1 / 5～9 / 3～7；每级：5 / 2 / 0 / 0 / 1 / 0。
- 普攻：物理，1格，间隔2拍；装备基底：EF02、EF07、EF08，各品质均适配。
- 来历：常在拥挤货道上为车队开出落脚处的短刃手，靠看清一格空隙而非横冲直撞贴近对手。
- 受雇动机：用可核验的走位本领换取雇佣，不要求同行者先替自己的过去作证。
- 顾虑：抢先一步反而堵住同伴的退路。
- 被动「顺步侧接」：真实自主移动后，下一次相邻侧后普攻获得20%条件增伤，本场最多2次；与同组基础姿态取高，不另乘一次倍率，不对正面普攻发奖。
- 主动「绕步」：本人向一个合法侧邻空格移动1格，优先脱离已锁危险或取得合法侧位。起手1拍，C3，每战2次；不穿占位或封边，不附普攻，无合法落点不空放。
- 优势：普通近战敌的朝向和公开预警就能提供用途。 真实走位后可获得有限侧后增伤。
- 局限：需要空格与合法路径，拥堵时无法绕步。 移动和攻击分别占动作，不因换位白送一次攻击。
- 关系：和薇拉交流路口的观察方法，自己的近战职责不依赖她或伴兽。 接受守缆卫提醒，不把护盾当作可以穿人的许可。

### M07 纸契师 · 用纸札标定合击目标的佣兵

- 定位：远程造印支援；为队友后续直接命中准备有限标准标记。
- Lv1区间：28～36 / 2～4 / 6～9 / 2～4 / 3～7 / 8～12；每级：5 / 0 / 2 / 1 / 0 / 1。
- 普攻：魔法，3格，间隔3拍；装备基底：EF04、EF07、EF08，各品质均适配。
- 来历：护运契据的誊写手兼行路术者，把耐水纸札用于标定已经看见的目标。纸上的记号只表示眼前的战斗机会，不代表掌握谁的身份或命运。
- 受雇动机：把出力、目标和报酬写清楚，亲自参与自己接下的护运事务。
- 顾虑：把一个标记当成不必再核对现场的命令。
- 被动「定札」：本场首次本人主动成功建立标准标记后，自己在下拍起得6私盾、持续2拍；包括BK04、BK09等本人主动造印，无效标定不触发。
- 主动「留痕札」：3格内可见、未带本方标准标记的敌人获得持续2拍的标准标记。起手1拍，C3，每战2次；沿用标准标记的下一次正直接命中加4规则，不附第二份伤害。
- 优势：不依赖敌方隐匿、护盾或施法就能标定。 首次成功标定提供本人有限自保。
- 局限：主动不造成伤害，标记要由后续正直接命中消费。 已有标准标记不能叠成第二份，身体较脆且普攻较慢。
- 关系：与闻笺交流记号的来源与交接，不替对方签字。 可为普通士兵、佣兵或英雄留下同一标准标记，不专属某种队伍。

### M08 近咒卫 · 贴近敌人的护咒佣兵

- 定位：魔法近战与有限反施法；没有施法目标时仍以伤害和一次自护作战。
- Lv1区间：40～50 / 2～4 / 8～11 / 0～2 / 8～12 / 10～14；每级：6 / 0 / 2 / 0 / 1 / 1。
- 普攻：魔法，1格，间隔3拍；装备基底：EF04、EF06、EF07、EF08，各品质均适配。
- 来历：负责贴近封闭咒器检查接缝的护运术者，把掌边的短咒用于近身交锋；普通攻击是魔法近击，不能隔着队友施拳。
- 受雇动机：以近场护咒的手艺受雇，亲自确认危险是否已经解除。
- 顾虑：把一声咒响当成已经制止了对方，而忘记对方仍在起手。
- 被动「护咒壳」：本场首次贴掌截咒造成正命中伤害后，自己在下拍起得6私盾、持续2拍；其他主动、落空或零伤害不触发。
- 主动「贴掌截咒」：对相邻可见原目标造成0.9倍魔法攻击的魔法伤害；若原施法cast仍合法且来得及，则延后1拍。起手1拍，C4，每战2次；与M04、BK08、PL09共用同cast单次延后锁，无施法时仍可为伤害起手。
- 优势：面对偏物防目标可采用魔法近击。 主动正命中即可获得一次自保，不必等对手施法。
- 局限：必须接近目标，普通攻击间隔较长。 不是眩晕，不能延后普通攻击、已到释放拍或已被延后的动作。
- 关系：与雾术师共用真实施法延后的时序约定，不能把同一次起手拖延两遍。 同护运枪卫分工：自己处理近场魔法，枪卫保留长枪封路职责。

### H01 洛恩 · 守约的盾匠

**战斗定位**：相邻共享防护与真正打断敌方起手。

Lv1：64 / 9 / 2 / 2 / 24 / 14；每级：8 / 1 / 0 / 0 / 2 / 1。普攻：物理，1格，间隔2拍。

**来历与动机**：留在暮汀修盾的后卫，为旧远征队保管裂口铜哨。主角归来后，他先清点担架和姓名，再判断哪些话值得相信。 让自己参与的一次出城有明确的归队点名，也保护自己继续作出选择的余地。

**恐惧与张力**：盾修好了，却再也找不到握盾的人。

**关系**：与莉安争论先护住谁、先治谁，但尊重对方核对伤者意愿。 保管旧队铜哨不让他代替缺席者发言。

**性格表现（设计稿）**：先核对人数再谈承诺；说话短，做承诺会交代能够保护的范围。

**人物弧线（设计稿）**：从独自背负每次伤亡，走向允许同伴参与防护顺序的选择。

**代表台词（设计稿）**：“站到我看得见的地方，咱们一起回去。”

- 被动 H01-P「誓线」：本场首次合壁成功建立时，自己得6独立私盾、持续2拍；与共享池分开，不因同伴进出重发。
- 主动 H01-A「合壁」：自己与首名相邻活友共享24盾，生效拍及随后2拍有效；每场1次，可配置开场或本人半血触发，离开链接不补池。
- 主动 H01-B「截锋」：对相邻正在起手的原敌造成1.0物伤，并在来得及且原cast可打断时真正中止它；起手1拍，C4，每战2次。
- 强项：共享池可以替链接中的同伴承担真实伤害。 截锋能实际取消可打断的原cast。
- 弱项：共享盾不是可花费私盾，邻友离开会断联。 截锋要相邻且来得及，不能追溯取消同拍已经到时的动作。
- 编队建议：前排相邻链接，靠共享池吸收集中压力；保留截锋窗口。

### H02 米拉 · 追查旧路的镜猎手

**战斗定位**：局部显露与合法折线路径的物理射手。

Lv1：38 / 13 / 4 / 3 / 4 / 10；每级：5 / 2 / 1 / 0 / 0 / 1。普攻：物理，4格，间隔2拍。

**来历与动机**：在灰栎边道做过多年的测绘，留意到路边石壁上反复出现的相似裂纹。她先提交亲眼见到的物证，不把猜想写成所有人的经历。 亲自核对旧路的异常，让别人也能复验自己的观察。

**恐惧与张力**：确实看见的东西又被简单归结成记错了。

**关系**：与许苇核对测绘记录，与秦姨交换旧镜片。 与赛琳共同保存误差记录。

**性格表现（设计稿）**：随身保留画错的地图页；习惯说明某个判断来自哪次观察。

**人物弧线（设计稿）**：从急于让人相信自己，走向让同伴能亲自复验并提出异议。

**代表台词（设计稿）**：“这里我量过。没量过的那段，我不会替它作保。”

- 被动 H02-P「量线」：本场首次物理命中已显露特殊部位时，该击目标物防视为降低10、最低0；不永久剥甲。
- 主动 H02-A「辨迹」：3格内已有虚影或可观察部位显露2拍，不造成伤害、不隔墙揭开未探索区域；C3，每战2次。
- 主动 H02-B「折镜箭」：总长4格内一次合法折线或直射，对首名合法敌造成1.3物伤；起手1拍，C4，每战2次，两段均验射线。
- 强项：可以针对可观察虚影和特殊部位。 折镜箭能在合法两段射线内选择一次折射，不依赖预放镜面。
- 弱项：没有虚影或可观察部位时辨迹不空放。 折射不是穿重墙，目标离线或路径被占会落空；辨迹不是标准造印。
- 编队建议：保留射线与折射落点，面对虚影和特殊部位时调整主动顺序。

### H03 莉安 · 把人当作原人的医者

**战斗定位**：有效治疗与倒地原实例的一次有限扶起。

Lv1：38 / 4 / 7 / 14 / 6 / 16；每级：5 / 0 / 2 / 2 / 0 / 1。普攻：魔法，3格，间隔2拍。

**来历与动机**：为归城者缝补名牌的医者，曾照顾过醒来后不再认识家人的伤者。她要求核对真实经历和当事人意愿，不把相同面孔当作所有问题的答案。 带还在的人走出险地，也为无法挽回的人保留真实名字。

**恐惧与张力**：维持了躯体，却认错了自己面对的人。

**关系**：与野战药师分担救护，同洛恩商量先护谁与先救谁。 和闻笺核对名册，但不让纸面交接代替伤者本人。

**性格表现（设计稿）**：点名时直呼伤者姓名；关心对方能否理解当前选择。

**人物弧线（设计稿）**：从害怕认错归来的人，走向与当事人共同确认身份与意愿。

**代表台词（设计稿）**：“先告诉我，你现在能不能听清我的话。”

- 被动 H03-P「余温」：本场首次实际治疗给原目标4私盾、持续2拍；零恢复或扶起不触发。
- 主动 H03-A「回暖」：2格内站立且生命不高于50%的原目标恢复floor(10+1.5×治疗强度)，夹至上限；起手1拍，C3，每战2次。
- 主动 H03-B「扶起」：2格内本场可救的倒地原实例，预约原格或合法邻格后以floor(6+0.75×治疗强度)生命起身；每战1次，同人全场只接受1次，起身当拍不行动。
- 强项：回暖可稳定支援受伤站立同伴。 扶起保留原成员和其已有经历，不发新人替身。
- 弱项：没有安全落格时扶起会失败，不能远程救回失联或被俘者。 起身不刷新次数与冷却，归城仍记倒地伤势。
- 编队建议：给治疗和扶起留出安全格；扶起不重开同伴技能额度。

### H04 薇拉 · 不依赖伴兽的边路向导

## H05与H06的设计改动

赫铎的「量缝」改为本次合法相邻普攻主伤扣盾前，先实际剥除最多4盾。它给一次普通攻击提供可观察的拆盾差异：目标102盾、原伤100时，先去4盾，随后原攻击吸收98盾并扣2生命，整次仍只有一个伤害包。无盾、非普攻、未相邻或零伤害均不奖励额外效果。这是本轮明确的技能设计调整。

赛琳保留真正施法被打断后的返还，另把「定星」原目标实际移出两格锁区而全空纳入同一个每场一次预算。生效时快照原目标位置，拍末才结算，排除后来的同拍推挤倒造原因；原目标要仍存活，本次不能命中别的敌人。目标死亡、无合法起手、仅被墙挡、仍在锁格、单纯延后均不返还，冷却也保留。

莉安扶起后的原人继续贡献、薇拉伴兽召回的真实避险与护盾吸收已补普通敌人流程证据；米拉折射相对直射的实际优势仍待更合适的普通样本，不能把这次扩充称为全部英雄已证明不可替代。
