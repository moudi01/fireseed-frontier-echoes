## 接敌阅读与战前调整

`intel`读取当前接敌或已探路公开节点，`intel B2`等只允许已公开且未清的本区遭遇；未接近／未探路的信息拒绝，战中不借此揭露隐匿位置。面板、单位位置、普攻射程／间隔、技能起手／冷却／次数／锁区、护盾／复起／召唤、弱点和应对提示来自真正将开打的冻结遭遇，包含公开威胁成长。初始单位、场景机制和预留援军分列，不把尚未召唤的预留当已在场。

既有接敌描述自动附敌情，浏览器只在原context中提供基础details阅读。读情报不推进时间、不重抽敌人。它提供可判断的信息，不保证自动选出最优阵型或克制收益。

战前EXPLORE可改部署、位置／朝向、姿态、本人已学两书槽、主动队列与开关，以及已拥有最多三PL。原次数、书槽与能力适配校验保持；学书／购买／领取仍在城镇，装备限实际携带。不能从远程留城者借书、从图鉴装备未学技能或临时取得未拥有方案；`fight`后配置锁定。

常用入口：`place ID q r 朝向`、`stance ID evade`、`book equip ID BK01 BK02`、`book queue ID 招式ID...`、`book auto ID 招式ID off`及`plan PLxx...`。先看本人学习库与`plan list`，命令中的ID须来自真实当前档，不是免费模板。

终战准备后的TOWN可读魔王，FINAL_CHOICE读已经锁定的魔王；FINAL_REGROUP可读管理员，但只允许原随队幸存者按原规则重布阵。连续战的生命、冷却、技能次数和消耗不刷新，不能把阅读入口当作中途城镇整备。

## 实际保护推进隐藏线

未发现时只显示无可回看的来信，不提前列整条任务、回执清单或私有因子。首封未署名来信由有效保护交付回执触发：现场处置须真完成，护送须实际接收，返城送医／药箱及运水须安全交付结算；承诺护送、仅装载或保全待完成均不算。

回城后手动跟进，阅读不代办：

| 动作 | 要求与结果 |
| --- | --- |
| `thread status`／`thread read` | 只读当前已发现内容；不付费、不推进步骤。 |
| `thread inquire CONFIRM` | 城镇收到首信后实际询问，仍为第一阶段；不能因收到信自动视作问过。 |
| `thread assemble EVxx,EVyy,EVzz CONFIRM` | 三份不同真实回执、至少两类交付，对证后进入第二阶段；不能同类三份或重复ID充数。 |
| `thread follow CONFIRM` | 至少七份、至少三类交付后，实际跟进第三阶段。 |
| `thread answer CONFIRM` | 十案原回执全部闭合且无不可撤销交易，并有正式ST-303研究交付，实际完成最后回信。 |
| `thread read inquire/assemble/follow/answer` | 仅回看已经完成的对应信件。 |

证据保存来源现场、趟次、原接收／结算回执及前后信链，归档后继续验证；伪回执、删步骤、改来源不能通过。旧作者保护／研究标记只按显式作者夹具处理，公开`author_fixture`提示，不作为自然取得证明。

B完美分级在原十案保全、无原人永久失落／被俘等要求之外，增加最后回信已完成的真实证明。仅私有因子100不自动完美，阅读或虚构收据也不能补门槛。未完信不等于删除B不完美分支；本轮完整最后回信／完美门槛主要由明确作者边界单元验证，不声称自然完美通关。
