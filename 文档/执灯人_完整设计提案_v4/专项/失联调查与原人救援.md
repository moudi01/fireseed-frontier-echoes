# 失联调查与原人救援

2026-10-28，灰盒0.49。人员调查归人员名册／搜救所；[独立线索册](独立线索册与固定调查.md)仅管理任务物、证词和研究记录。本批补齐原有“失联但尚无已知转运点”的运行入口；失联记录、到场调查、确认地点和原人救援使用同一份名册与同一条期限，不另外赠送替代队员。

## 来源与人员状态

本批灰盒规则：自然开局的普通远征，在非四魔将战中实际败战后，未安全退出的随队人员先登记为**失联、去向待查**。登记绑定真实败战、当趟随队实例、最后出现的区域／地点与当日结算；不通过随机抽签生成失踪者。野生敌人只造成战败，后续去向需要调查，不能把野兽写成人格提取者。

四魔将战、已知救援／原物调查专线和固定教学仍沿用已明确巡收的转运记录。独立试验队保留“已知转运点”夹具，不能把其预置许可当作自然失联调查证据。序章旧名册属于叙事背景，没有本轮真实人员实例，不生成免费补员任务。

失联与已确认被俘都占原人的现役位置，保留原ID、等级、经验与穿戴装备。二者不能编队、交易装备、受护理或学习技能；调查没有创建第二份人物实体。去向未知时关闭直接救援和原物联办入口，确认后开放原批次入口。已安全护送离队者不再次登记失联。

## 搜救所与固定调查

人员调查不列入线索册。搜救所统一提供下列入口，旧`missing ...`命令仅作兼容别名；改入口不清除已有进度、人员记录或期限。

| 动作 | 规则与结果 |
| --- | --- |
| `rescue status` | 查看失联批次、原人员、最后出现地点、已记录步骤与最迟搜救日；记录属于人员名册／搜救所，不列入线索册 |
| `rescue investigate quote CAP批次` | 显示调查补给、返城日、随后最早救援日和届时到期者；来不及另行救援时明确警告，不暗中延期 |
| `rescue investigate start CAP批次 CONFIRM` | 当前合法小队实际出发；基础1补给，搜救所Lv1沿固定搜救短线减为0；不要求建楼才能调查 |
| `rescue investigate inspect tracks` | 在最后出现地点核对该批队员的行进痕迹，保存与原败战绑定的记录 |
| `rescue investigate inspect marker` | 先有痕迹记录，再沿交接标记确认支路编号；未完成第一步不能越过 |
| `rescue investigate return CONFIRM` | 回城交存并结算1行动日；两项齐全且原人尚未到期，确认原批次转运点。否则保留部分记录或登记逾期结果 |
| `rescue CAP批次 CONFIRM` | 确认转运点后，沿既有GR02E一战救回原人。不是调查一完成就发还人员 |

调查是固定0战短线，不抽普通地图、随机掉落或重复奖励，不给铜晶、材料或经验。调查确认的地点可随后按原有搜救所Lv3同走廊规则与原物调查联办；尚未确认的地点不能直接联办。

每次出发到归城只结算1日；查看、检查线索、重复检查、存档与离线不额外加日。做到一半可以返城，原步骤跨趟保留，重开仍在原地点；下一次实际出发仍需重新支付该趟补给并结算该趟行动日。调查期间不能远程补员、建楼、采购或安排另一场救援。

调查属于一次实际出发，已购买的“下一次出发”工坊整备和设施服务按原规则绑定本趟，不因没有战斗而无限保留；城镇在下一行动推进的伤势、施工和已付补训仍正常结算。调查队必须满足正常随行、部署及健康限制，不用虚构侦查员代替真实队伍。

## 期限与失败

普通失联仍沿该次失败结算日C及难度模式记录最迟搜救日：标准C+3，宽松C+5。本批不另加“发现后再倒计时”。调查返城确认只改变已知地点，不改C、截止日或原人ID。

因此标准模式若第C日失败，第C+1日调查归城，第C+2日可救援；若调查中途返城再补完，可在第C+2日确认并于C+3截止日救回。仍按既有顺序先结算当日成功救援，再处理到期未救者。

如果调查返城本身已经达到截止日，原人按原期限进入永久损失记录。即使两项现场调查齐全，也不能再开放一个救援死者的新入口，不复活、不退款补发、不用新同类单位顶替。

确认后的救援败战保留旧批次期限，调查／救援队另记新捕获批次与自己的期限。旧线索不被新失败覆盖。全人类名册已经不可恢复且没有救援对象时，仍按原C结局规则处理；仅失联或尚在期限内不能提前判全员消失。

## 保存与证据

失联线索绑定败战战报中的原随队名册，人员始终只有一个位置；恢复后保留原捕获历史以供核对。每项现场记录绑定实际调查趟次，确认地点必须有两项记录、真实返城结算和仍有效的原期限。日期、物资、状态与回执原子保存；写盘失败不留下半确认地点或重复扣费。

实际验证使用自然开局、真实教学、正常招募和刻意少部署导致的真实败战，没有资源或角色强化。随后从同一失联检查点验证分段调查并截止日救援、逾期调查、救援再败三种完整结果；不据此评价整体战斗平衡。详细记录见[0.49模块报告](../../../原型/火种计划_远征灰盒/验证记录_v049.md)。
