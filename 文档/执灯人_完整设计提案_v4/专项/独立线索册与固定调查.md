0.49归属修订：[失联调查与原人救援](失联调查与原人救援.md)归人员名册／搜救所，人员不列入本线索册。本册仅管理任务物、证词及研究记录；原物自取及联办规则保持原样。

2026-10-28，灰盒0.48。[用户明确方向] 任务物品单设线索类系统，不共用普通背包。[本批实现补全] 用统一线索册展示查阅、核实、定位、收录与使用资格；原物、证词、研究来源仍各有真实记录，不复制第二份库存。

## 范围与保护

四件执念原物、KS01—KS03及Agla进入独立任务记录。线索册不占装备两槽、普通携行袋或材料额度，不参与普通开箱、买卖、拆解、丢弃、加工重铸。已经取得的线索和任务授权在普通败战后保留；其保护不扩展到钱、材料、消耗品和普通装备。

实物与证词不是同一条件：看到名称不等于取得原物，核实证词也不自动发放物品。魔将记忆仍同时核对原物与证词；研究与Agla沿原固定来源、实际建设和制造回执。Agla是独立任务载体，是否携带仍按终战前夜选择，不因放在线索册就自动越过制造或携带前置。

ST-303前只显示表层物名、持有人证词和已开放的任务条件。KS使用现行分阶段名称；未开放的执念线索不展示后续人物、地点与用途。线索册没有新增人性因子来源。

## 固定调查与联办

`recover quote MG01`先列任务、费用与结算日；`recover start MG01 CONFIRM`出发。独立调查1战、1行动日、基础1补给，搜救所Lv2/B减为0。原委托费与出发补给分开记账。胜利并安全结算后收录原物；撤退或败战则保留同一地点，按现有规则结算伤势、被俘和物资损失。没有钱晶、材料、首领首奖、应召印或主线经验奖励。

搜救所Lv3可使用`recover quote MG01 CAP-0001`和`recover start MG01 CAP-0001 CONFIRM`联办。必须存在真实被俘批次，原物锚与该批次来源在同一区域走廊，且本趟结算日不晚于救援期限。不能把两个任意地点合并，不能借联办延长期限。两点基础补给分别核算：三级救人点已减至0；原物点只有B支减至0，A支仍为1。

联办固定先救人、再调查，共2战、1行动日。第一点完成后停留，可调整原随队人员的部署、位置、朝向和技能模式；生命、侵蚀与已耗准备品保持，不远程补员、购买或换装。两战仍是独立战斗，沿现有每战技能规则；不是终战的连续时钟规则。

此时可`recover return CONFIRM`仅带救援成果返城，或`recover continue CONFIRM`继续调查。已救人员进入安全转运，不能在第二点立刻作为援军上阵；只在本趟最终结算时回到留城名册。第二点撤退或败战不撤销第一点救援；调查队败战产生自己的新捕获批次，原有成功救回者不被再次捕获。没有完成调查的原物继续留在固定锚。

本日已成功救援先于到期处置；随后结算旧伤与施工，再登记新伤、新捕获。救回者的新伤不会吃掉同一次自然恢复。两点之间保存再加载不额外加日；最终回执与人员、原物、资源一起原子保存，失败提交回滚。

## 验证与边界

实际初始士兵完成单线调查和撤退重试；联办使用明确预设的搜救所Lv3/B，人员、招募费用和战斗仍实际执行。验证覆盖截止日成功、救人后早返、后点败战、点间续档及提交失败回滚。联办等级预设不证明三级建筑的自然成长或经济平衡，四个地区的美术及完整剧情演出不在本批范围。
