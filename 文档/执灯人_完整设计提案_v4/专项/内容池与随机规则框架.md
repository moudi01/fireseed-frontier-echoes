## 1 审查结论与目标

现有内容足够建立第一轮候选登记、资源转换检查与条件概率分析，但不足以直接给出整趟远征的丰富度或完整通关概率。最优先补的是装备与加工之间的关系，其次是敌阵的组合职能和普通事件的玩法变化；增加条目数量本身不能保证更多有效选择。

目标是让随机结果改变玩家当下可用的策略，让玩家能够应对坏运气，同时保留意外收获的价值。验证不规定第几趟必拿什么；记录的是给定随机规则下的机会、缺口与极端情况。玩家的路线和取舍采用多种明确策略作压力测试，不把任何策略当成对真实玩家的预测。

完成本阶段的标准：每项已有规则有来源；每个缺口有归属和可判断的完成条件；每个随机环节能说明抽什么、按什么过滤、何时锁定及空池怎么办；未知权重保留未知，不默认填等概率冒充产品规则。

## 3 四个系统的主要缺口

### 3.1 怪物：先补战术组合登记

MON-01：把普通随机、教学、救援、剧情与终局分开登记。现有生态标签、威胁和allowed_contexts继续使用，新增“候选用途”统一索引；只有满足该槽位条件的完整敌阵参与抽取。

MON-02：给敌阵补充主压力、支持关系、反制窗口与组合冲突。可以从已有机制开始，例如EN04提供保护、EN15提供有限治疗、EN17形成正面线压；三者各自有说明，不等于组合后仍存在充足窗口。审查应覆盖预警重叠、后排可接近性、撤退可达性和基础队伍的应对途径。

怪物预算不读当前队伍来暗中增减难度。候选适应只读取已有规则允许的真实见证历史和有限卡槽；不能把“历史适应”扩大成“看玩家背包后专门抽克制怪”。

后续新增物种必须指出它带来哪种现有池缺少的压力或组合关系。只改名字、外形和血量的变体不能计为新的战术职能。

### 3.2 事件：补普通玩法变化与出现结构

EVT-01：章节、地区、两趟冷却、单趟最多2卡已经明确；现已提供POOL-SAMPLING-0.1初始配置（新卡3／人性2／旧普通1），不强制类别配额，最终权重仍需校准。定向委托须先预留原事件槽，剩余位置才抽普通池；已保全/出卖案件只能读后续，不能再次成为奖励机会。

EVT-02：十个人性事件保留四种执行方式；新增24地区事件与42普通卡职能登记已完成。以下是职责分类，现行具体卡片见八区内容池专项。建议按下列职责登记待写内容，尚未写完者不进正式池：

| 待补职责 | 必须明确的实际变化 | 不能偷渡的内容 |
| --- | --- | --- |
| 情报与路线判断 | 提前知道哪个既有危险或收益，是否影响继续/返程 | 免费清敌、改写已锁敌阵、凭空开新通路 |
| 整备与构筑调整 | 提供哪个已有合法能力/配置机会，付什么成本 | 直接附送一套完整最优组合 |

所有事件继续遵守知识门禁。选择前说明玩家能知道的物资、人员和风险后果，里层解释不通过随机权重、选项标签或日志提前透露。

### 3.3 装备：初审缺口与补全要求

GEAR-01：需要一张家族功能矩阵，逐项说明适用角色、与其他装备的替代关系、在哪种队伍/敌阵中值得更换，以及获得它后能否改变配置。适配不同兵种不等于产生不同玩法；也不能仅因属性型装备没有触发效果就断言它没有价值。

GEAR-02：普通掉落、商店升品和人性交易提供同一套模板。Q3物品的价值必须与其确定获取路径比较，不能只用掉率低来证明珍贵。固定交易的自选高品质奖励保留，审查时单独统计它对随机掉落升级空间的挤压。

需要同时区分三种结果：能装备、比已有装备更合适、值得因此改队伍。只有第一种成立的“可用率”，不能作为构筑变化充分的证据。

### 3.4 加工：限定纠偏能力，检查资源绕行

PROC-01：现有Q1商店统一8铜，覆盖八家族；Q1拆解返还1份主材。因此存在以下确定路径，均有成本，并非免费套利：

| 购买后拆解 | 当前转换 |
| --- | --- |
| EF01/EF02/EF06 | 8铜→1铁料 |
| EF03/EF07/EF08 | 8铜→1木纤 |
| EF05 | 8铜→1草药 |
| EF04 | 8铜→1晶屑 |

EF04意味着晶屑并非只能依靠后续地区随机掉落或材料委托取得。需判断这是否是有意的兜底供给，再与地区投放、建设消耗和阿格拉材料需求统一。不能一边保留这条路径，一边在概率报告里宣称“连续没掉晶屑就一定卡住”。本轮保留现值，未自行封禁或涨价。

TINDER-1.5中，买Q1再升到Q3总铜为8＋12＋24＝44，另需12份主材＋2木纤＋4晶屑、累计3加工进度，并满足工坊Lv3及ST-303完成。重复材料标签要合并，例如EF04合计16晶屑＋2木纤；不能把主材占位符当第五种材料。升品同家族且产物固定，所以随机高品质掉落的一部分价值是节省已知投入，不能假设它是唯一获取通道。

PROC-02：建立操作登记表，区分启用与预留。当前野外升品和换装明确未进入事件池；计算时不可假设玩家随时能把错装备换成目标装备。加工不必自身随机，确定的纠偏途径可以帮助玩家处理坏运气，但应保留材料、解锁、家族或机会方面的真实取舍。具体新增限制需后续功能设计，本稿不擅自添加加工失败率。

## 5 随机规则框架

### 5.1 四种状态

**已有规则**来自现行文档，仍可能需要平衡；**框架草案**是本轮提出的统一接口；**待校准参数**保留null；**预留功能**尚不可抽取。补齐框架不等于把待校准数值一律填1，也不等于启用预留加工。

### 5.2 抽取顺序

1. 明确本轮设计版本与抽样配置，分离固定剧情、教学、定向委托和普通随机内容。
2. 保存出发上下文与各随机流种子；按地区、公开威胁、任务和兼容关系联合绑定路线、棋盘及敌阵。
3. 预留定向事件位置和既有整趟奖励额度，再筛选普通事件、奖励来源及所需安全接收服务。
4. 检查必经目标与出口可达，保存本趟地点、敌人、事件和奖励实例。失败不能靠删除任务门槛“修好”地图。
5. 对明确允许延迟形成的行军方案候选，在首次展示时保存资格快照和完整选项；玩家后续操作不重抽。
6. 实际选择、领取或加工才消耗额度并保存结果。已承诺交付不冒充已完成行动，保存失败不换种子。

第5项是解决“出发锁随机结果”与“方案要根据当前能力筛选”的草案：出发锁目录、种子和请求身份，首次展示锁合法候选快照；之后换队再打开仍是原选项。它不允许重洗地图、敌阵或已经生成的物品。具体受约束抽样算法仍待登记，当前不能声称已经实现。

### 5.3 各环节抽什么

| 环节 | 抽样单位与现有边界 | 尚待确定 |
| --- | --- | --- |
| 地图 | 满足连通、目标、2—3战及既有地形要求的组合 | 拓扑与兼容组合的选择分布、有限重试次数 |
| 敌人 | 合法完整遭遇模板；教学/任务类型不混入普通槽 | 候选权重、重复修正、组合职能审查 |
| 事件 | 满足章节、地区、认知、案件与冷却要求的卡 | 卡片权重、类别占比 |
| 装备 | 已有：主题池均匀不放回给最多2家族；先选家族，再揭示共用的一次品质结果 | 内容池改变后的品质与保底校准；本轮不改现值 |
| 材料 | 已有：按地区权重逐份独立有放回抽取，受真实领取额度限制 | 加工转换关系明确后的投放校准 |
| 行军方案 | 最多3个不同ID，至少1个当前可用、最多1个暂缺组合一端 | 合法选项集合的权重与抽法；不足3项时草案允许少给或放弃 |
| 加工 | 已启用操作按公开确定产物处理，不自动增加一次随机判定 | 后续新增操作、纠偏范围及成本 |

抽样必须先做硬条件过滤，再使用版本化权重。不能先抽到非法结果再偷偷换成某一张，使最终概率与展示不符。若使用约束抽样或重试，报告必须记录它如何改变有效分布。

### 5.4 随机流与重复

[框架草案] MAP、ENCOUNTER、EVENT、GEAR、MATERIAL、PLAN使用独立流，键包含周目、远征、领域、槽位/领取ID、算法版本。候选按稳定ID排序；禁止依赖进程随机哈希。看一次说明、调整镜头或先点另一个箱子，不能消耗敌阵随机流。

同一远征的回走、读档、暂停和保存失败重试复用已有结果。普通奖励额度不因提前护送或重开界面重置。品质保底沿用实际提交装备领取才推进的规则；剧情交易装备不擅自纳入普通随机保底。

本稿没有选定具体伪随机算法，不能以“已有种子字段”宣称不同程序版本会产生相同结果。算法、稳定排序和序列化规格须在实现前一起定版。

### 5.5 空池与异常

| 情况 | 处理 |
| --- | --- |
| 普通事件过滤后为空 | 观察/整备，不新发奖励，不暗增战斗或日期；不绕过知识门禁 |
| 定向案件缺地图服务 | 出发前明确改用独立短委托或暂缓，不能先派人再假装送达 |
| 必经地图/敌阵无合法组合 | 报生成验证失败；只在同约束内重试，不能无限重抽或凭空削敌 |
| 装备池无合法来源、额度不足 | 不扣费、不消费领取凭据；允许放弃或合法整理，不发虚构补偿 |
| 方案不足3个合法选项 | 草案：展示较少选项或放弃并说明，不塞重复项、不强行给三张废卡 |
| 加工未启用、输入不合法、存储不足 | 操作不可提交，保留原输入；不先扣费后吞产物 |

生成有限重试次数仍待校准；未提供该参数的配置不能冒充可运行的生产生成器。统计应保留失败样本，不能只展示成功生成的种子。

## 6 路线数量与有效选择不是一回事

MAP-02：当前普通非战分支可回访，移动不另扣行动日，回访不加区域侵蚀；因此“有6条前进路径”不能直接解释为6种互斥策略。若同趟能够绕回拿到两支相同收益，差别可能只剩访问顺序。

后续应统计共享额度、事件展示上限、敌阵互斥和真实状态变化之后，不同走法能得到多少种可行结果。先审查现有预算与信息差是否足以形成取舍，不为增加压力自动添加走路扣血、每步侵蚀或新的隐藏计时。

## 7 现在能算什么、以后怎样算

可以立即进行来源完整性、候选过滤、资源转换以及局部条件概率计算。例如RG01材料权重为木纤4、草药3、铁料1，若确实领取4份随机材料，则没有铁料的概率为(7/8)^4≈58.6%，期望铁料0.5份。这不是“一趟远征没铁料”的概率，因为实际领取数量、固定委托、买后拆解、返程和损失尚未纳入。

| 指标 | 必要输入 | 输出必须区分 |
| --- | --- | --- |
| 候选覆盖与重复率 | 已登记用途、解锁/地区上下文、明确权重与历史 | 条目ID重复与相同战术组合重复 |
| 材料短缺分布 | 地区权重、实际领取份数、其他取得途径 | 条件掉落短缺与整趟实际库存短缺 |
| 装备机会 | 主题候选、队伍和已有装备快照 | 能装备、实际升级、值得改队 |
| 组合机会 | 方案抽样、解锁、书与能力状态 | 被提供机会、玩家选择、战斗实际生效 |
| 加工价值 | 转换图、解锁、材料与铜成本 | 可达路径和成本向量；不随意把所有资源换算成同一分数 |
| 路线取舍 | 生成规则、回访、共享额度、锁定顺序 | 视觉路径数量与互斥结果数量 |
| 多趟恢复能力 | 覆盖所用机制的战斗/捕获/经营模型及策略 | 各策略的结果分布；未建模遭遇单列，不填假胜率 |

未定权重可用显式的等权或偏重场景做敏感性分析，但必须标为假设配置，并比较多个配置。null不得静默当成均匀分布。每份结果记录输入哈希、版本、种子、策略、实际候选数量、剔除原因、空池/回退次数和指标分母。

“保守撤离、追求构筑机会、优先已公开物资、坚持保全承诺”是压力测试策略，不是玩家人格分类。不得将资源优化策略自动写成趋利C。
