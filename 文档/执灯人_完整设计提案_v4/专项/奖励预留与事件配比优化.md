## 本轮决定与适用范围

普通远征改用“先保障事件选择，再安排可选战利品”的预留顺序。短途2区／中途3区／长途4区、每区基础3处事件与条件第4处、现行收益上限均保持。目标战完成仍登记16铜＋2公共晶，精英实际胜利仍增加8铜＋2公共晶；**上轮样例中每区固定2材料的压力预留，改为出发前按剩余额度安排0或2材料**。这项材料原本就不是所有目标战必掉的承诺。

在可用的原事件池内寻找更完整的选项组合，不改60张卡的正文、数值、原权重或人性收益，不额外增加“只为省预算”的空事件。配置见[奖励预留与事件配比配置](../校验/奖励预留与事件配比配置.json)，离线实现见[ChoiceSampler](../校验/choice_sampling_model.py)，证据见[校核报告](../校验/奖励选择空间校核结果.json)。此前[JOINT-SAMPLE-1.0](联合抽样验收样例与失败边界.md)仍可复算原压力配置与旧选卡策略；新普通远征的奖励分配方向以本篇为准，旧样例不能直接当新方案输出。

只作用于新生成的普通远征。教程、固定委托、救援、终局和已锁定计划继续沿原规则；既有掉落承诺与外部预留不得被腾挪。D0材料上限仍为4N，D1为6N，D2为8N，N是区域数；事件铜8N、事件晶N、拾得消耗品N、新增歇息1次维持；装备／书采用上方0.30说明，保留长途额度，只提高D2短中途上限。

## 问题与预留顺序

原参考对一张卡先尝试双选项，再尝试关闭其奖励选项，之后才换下一张卡。加上每区先占2材料，会让“内容够数”与“玩家有得选”脱节。例如侦察与制作都带回收材料备选，再叠加材料或消耗品事件，很容易争同一份材料预算。

改后顺序：

1. 先核对路线、门禁、普通候选容量、真实服务和外部已承诺奖励。外部预留永不挪用，找不到合法路线不扣出发物资。
2. 暂不预留可选的目标材料，按原权重与冷却生成一份可行事件计划。每卡仍按全部开放选项的各资源最大值预留，而不是假设玩家会选便宜选项。
3. 固定已出现的人性案件及其地点、待办状态和完整选择；固定全部已有事件地点，包括已生成的第4处。普通卡可以在兼容地点间重新组合，先尝试每条路径0个预算限制，再尝试更低的限制数。每条路径的限制数都不得比这份初始可行计划增加。
4. 搜索每档最多1200节点。若耗尽，记录未决并保留可行计划，不能宣称没有解。随后尝试单卡替换及成对替换：被置灰的卡与一张争用同一路径预算的普通卡一起重组，两张均保留完整选项。成对尝试每计划最多2000组；每次成功必须减少限制，且重新核对全部路径的预算和敌阵。
5. 最后按种子顺序，在所有相关路径都还有2份材料余量的地区，为G锁定一个RB-MAT2。没有余量就不安排这项额外材料。目标佣金与精英奖励不受影响。

这里的搜索预算是离线参考参数，不是最终生成耗时指标。该流程不保证全局最少置灰、最多目标材料或最佳事件配比。基础计划生成仍有原20000节点上限；基础可行性失败与已有计划的优化搜索耗尽是两种不同结果。

### 预留与结算不能混为一谈

若一张卡让玩家在2材料与1件装备中二选一，预留2材料和1装备额度，实际只结算选中的一项。对每条合法路径求和；互斥支路不错误累加，同一路径所有可能选择必须承受得住。护送、返程与货物保全继续走真实交割；EV09的2份载重预留保持，EV25不套用该规则。

选择侦察、跳过奖励、消耗、交易或丢弃物品后，未使用的预留不会转给后面的事件、追加目标材料或刷新掉落。否则玩家仍会被迫规划领取顺序，且可能通过回访改变收益。出发前锁定事件、目标奖励和敌阵，读档原样恢复；这不是按途中表现实时补偿。

这项调整会改变材料的获取地点：偏好只打目标、不处理事件的玩家，可能获得更少材料，仍拿到原目标佣金。材料上限是最多可领额度，不是必达收入；选择情报、构筑或其他资源，意味着放弃相应材料。此代价需要后续经济实测，不能称为收益完全等价或平衡已完成。

## 事件配比：互补需求，不排固定流程

| 事件功能 | 原有代表 | 组合时关注的冲突与互补 |
| --- | --- | --- |
| 情报、敌阵选择 | EV29—EV52中的侦察与改路 | 对真实未揭示目标有用；侦察的材料备选也须预留，不能因为主选项免费就记为零成本卡 |
| 制作与携带物品 | 各区工作棚、EV53／57／59 | 制作依赖自带材料；拾得消耗品同时占材料与拾得次数，不能把两种服务都当免费补给 |
| 材料、装备与运营资源 | EV02／06／21／55／58／60 | 分摊不同收益额度；保留EV55用生命换较多材料的高收益选项，不一律选低收益卡 |
| 构筑与准备 | EV56／60 | 提供原有方案选择，受槽位与明确替换规则约束；不因当前队伍缺某方案而暗定卡 |
| 恢复与环境应对 | EV54及原有效果 | 保持新增歇息整趟1次，固定S和跨区扎营另算；不能拿多张恢复卡绕过上限 |
| 人性案件 | 原10项 | 出现与完成由原章节、冷却、终态和真实接收条件决定；优化不能增塞人性卡充当便宜填充 |

这些是策划审查维度，不是“每区固定一补给、一制作、一情报”的强制配方，也不保证玩家一定先遇到补给。候选权重不变，但联合约束与择优会影响最终出现频次，因此新分配需要重新观察长期重复度。报告保留按功能与事件ID的样例出现次数，仅作诊断，不能当真实概率。

地图模板、固定S和出口仍沿八区联合布点；修复事件组合后重算改路两敌阵的共同棋盘与EV08目标绑定。模型只证明登记关系，真实视线、绕路和寻路仍需场景验收。

## 剩余置灰如何处理

| 原因 | 设计处理 |
| --- | --- |
| 作者预留不足 | 优先换合法普通卡组合、后排可选战材料；剩余限制标记CHOICE_BUDGET_REVIEW_REQUIRED，进入作者复核，不把内部预算提示直接发给玩家 |
| 制作原料不足、背包已满 | 明示具体缺项；保留其他选择和离开。允许按原背包规则整理后再确认，不能自动丢弃、使用或领取 |
| 没有可治疗目标、侵蚀已为零 | 根据实际效果判断对应选项，不能收取次数后做零效果恢复；仍保留其他合法选项 |
| 侦察目标已揭示、改路目标已接敌 | 明示目标状态，保留仍有效的替代选项及离开；不换卡、不生成新敌阵 |
| 人性案件已交割或接收条件缺失 | 生成前排除；途中重新核对实际交割条件，不伪造善行，不关闭保全选项来诱导出卖 |

“预算上双选项开放”不等于“此刻两个动作都能执行”。缺材料、队伍状态和已发生的探索结果属于玩法条件；生成预算不足属于作者需要修复的问题。离线SUCCESS只表示计划合法；即使标记BUDGET_CHOICE_OK_NOT_RUNTIME_VERIFIED，也不代表可以跳过体验与引擎验收。

72组正常／终态样例全部生成成功，三种可行策略的事件地点总数一致。普通样例限制总数下降约98%，全案件终态组下降约91%；这些是本批样例的计数变化，不是未来所有远征的保证。另有D1／D2各三种长度通过额度与生成检查。

配比确实发生变化：普通样例的现场制作地点由65降到48、侦察由59降到47、改路由86增到104、恢复由32增到43。它们仍受原条件和次数上限约束；这种倾向需要继续观察，不能只看置灰下降就宣布各类型比例合理。两组共出现68种不同事件分配，EV55在12个共享地区实例中仍保有完整双选项，未因材料占用高而被全面剔除。普通样例的人性地点计数从117到114；在新可行计划的优化前后固定为114，没有靠多塞人性卡获得改进。

26个边界情景中14个合法、12个按预期拒绝。JS12在移走额外目标材料后变为合法，但仍有4个预算限制，需要作者复核；新增CS26将外部材料预留占满，仍明确失败。缺失三类服务的JS07保持每区3处事件，但还剩2个限制。因此**0—1只描述上表两组样例，不能外推到缺服务或额外预留等极端配置**。JS18关闭出卖是案件待办状态，未计为预算置灰。

原始状态中仍受限的请求是B1-MEDIUM-11、B1-MEDIUM-47和B1-LONG-47，对应4条路径各1项。它们连同终态组的剩余限制进入作者复核；部分更低限制搜索耗尽，尚未证明最优。固定2材料又强求全选项的对照在1200节点内19组成功、1组明确失败、16组未决，说明只改变选卡优先顺序不足以稳定解决这批样例。

一个具体变化见[长途前后计划](../校验/奖励选择空间样例/normal_B1-LONG-47.json)：成对重组将雾痕林缘EV55换成原有EV01，使EV32的材料备选重新开放；EV55自身的4材料选项数值不被削弱，并继续在其他兼容计划出现。这是出发前的组合差异，玩家遇到卡片后不会被换卡。

以原36组输入逐种子对比：旧固定目标材料、只调整材料分配、调整分配并优化普通事件组合；另将这36组的全部人性案件设为已保全，检查普通玩法能否独立运转。额外保留26个边界情景，包括冷却、无服务、知识门禁、待办护送、外部预留与搜索上限。

固定目标材料且强求全选项的方案也进行1200节点对照；其SEARCH_LIMIT只表示未求完，不能计为内容无解。新方案保留所有初始地点，不靠删除事件降低置灰；人性事件在优化前后逐项一致。
