**[用户确认] 一个区域是一张连续的小地图，战斗与事件分布在这张地图中。** 玩家在场景内实际行走和探索，岔路是地形中的道路。路线图承担记录与导航功能，不再通过逐层选择节点切换地点。

## 关卡目标

把“下一步选哪个节点”变为“看见前方地形与线索后，决定走到哪里”。玩家能从入口出发，沿真实道路抵达任务目标、事件地点、战斗场和返程点；地图允许支路、环路、局部开阔地和回头探索，不要求全部地点依序访问。

MULTI-1.1已增加跨区远征：灰栎边道与断誓堡垒仍是两张不同区域地图，只有已登记相邻关系的地区可通过目标出口衔接，不能从灰栎直接跳堡垒。一个区域内部可有林地、废棚、桥头等多个地段，但这些地段不各算一个新区域，也不因跨过美术拼接边界重复收取侵蚀。

验收首先看空间行为：普通移动不打开路线选择弹窗、不切换到另一间独立遭遇房；能沿同一路径走回已访问现场；敌人和可交互对象在该地点有稳定身份与位置。地形可以内部拼接或流式载入，玩家可见的道路、朝向、对象状态必须连续。具体按键沿项目操作规范，此处不增一套移动按键。

## 机制设计

### 空间布局

| 空间要素 | 地图上的实际形态 | 设计边界 |
| --- | --- | --- |
| 入口与返程 | 与镇外道路连接的安全落脚处；其他撤离点须有明确服务来源 | 初始可见、可返回；触发返程须确认，不因经过出口就自动结束 |
| 主目标 | 地标、任务对象或固定目标战斗场 | 可达、可辨识，不要求清完所有支路；四将仍遵循既定任务与首次奖励 |
| 普通敌群 | 守路、据点警戒或栖地中的固定编队 | 有可读边界与危险提示；开战前仍免费公开实际敌阵；不新增实时追击系统 |
| 精英据点 | 可见的危险支路或可选择的较强目标 | 进入前提示，不挡唯一合法主线路径；独立挑战与替代战分别计预算 |
| 事件地点 | 人、废车、告示、工作台、营棚等 | 主动靠近并交互；看见不等于选项确认，不在每个岔口自动弹卡 |
| 安全整备地 | 入口营地、已确认安全的棚屋或避风点 | 换预备、使用已有物资、查看路线；安全不等于免费回满 |
| 补给服务 | 真实存在的补给设施、物资或已登记制作服务 | 保证长流程具有基础补给机会，具体成本和数量须列入地图预算；不是每个事件都能恢复 |
| 支路与环路 | 可实际通行的侧路、绕行路、返回连接 | 能绕开的是可选危险；若可绕过战斗，就不把该战算作必经战或免费发胜利奖励 |

地形、敌群、事件和任务位置要联合生成。不能先随意散点，再用空气墙或传送把玩家串成七层路线。至少一条完成目标的合法路线不经过可选精英；可选据点不承担所有基础补给。关卡验证要考虑玩家跳过事件、绕过可选敌群、直接接近目标以及原路返回的情况。

### 用户动线与原地战斗

1. 从入口进入连续地图，灯随队照亮附近道路。远处轮廓、环境声音和地标用于提示，尚未发现的奖励与剧情不提前公开。
2. 玩家沿可走空间探索。对事件对象主动交互；关闭窗口、走远或PASS按REVISIT-1.0暂离，不消耗物资或关闭事件；返回原地点继续。已提交步骤与已完成结果保持原记录，明确放弃另行确认。
3. 队伍接近敌群的可读接敌边界时停止探索，公开该处完整战斗场和敌方实例，进入部署确认；在正式开战前可退回边界外继续探索，不生成战果，也不产生战后侵蚀。已付出征费用和已使用的预备物资不退；再次接近恢复同一敌群、场地与已承诺状态，不重抽。远远看见敌人不自动开战。
4. 正式开战后使用原自动战斗规则。按地点选择的现行多形状六边棋盘嵌在当前场景；树木、河沟、墙、单位朝向及位置映射一致，不传送到通用竞技场。局部战斗边界事先显示，战中不能靠探索移动走出边界脱战，只能按原撤退规则处理。
5. 战果保存后收回战斗显示，队伍在同一现场集合，继续探索或返回。战斗掉落和事件物件使用稳定回执；绕行、回头、退出续玩均不刷新。

一个战斗场的参与敌人由出发配置与接敌预览确定，不把相邻据点临时拉入同一战。相邻战斗场不能重叠部署区或造成无法避免的连锁触发；入口、事件交互和安全整备地不得落在未预告的接敌范围内。原地战斗仍无战中手动移动、即时施法或用药。

### 随机、发现与保存

新出发锁定一张区域地图的几何、连通道路、战斗场、敌群、事件及服务、奖励、危险暴露地段和照明锚。确定结果不等于向玩家公布结果：迷雾、侦察和接近提供分级信息；随机性体现在新一趟的布局与内容变化，不靠玩家走近时暗改敌群。

区域实例、危险地段、事件实例、敌群与战斗槽分别有ID。危险暴露沿原已登记地段首次进入回执；同地回访不加、每走几步不加、相机看见不加；一个新地标不能自行制造额外+5。后续延长流程时，必须重算危险地段数量与战后侵蚀，不能直接放大旧惩罚。

保存包含世界位置、朝向、已揭示区域、对象状态、战斗场绑定及未完成交互。加载恢复该位置和同一地图；返回入口不重新抽图。地图页可标记已知地点和通路，不允许点击未到目标直接传送或跳过途中危险。

## 难度评估（具体数值由MULTI-1.1接续）

连续小地图解决空间探索方式，不自动解决单趟长度。原2—3战、最多2事件保留为RT2／RT3短途与教程的参考规模，退出“所有常规远征固定上限”的地位。现行2／3／4区长度已确认，首版总量6—8／9—12／12—16战与6—8／9—12／12—16个事件位置见MULTI-1.1，均仍待试玩。新常规地图的可放行数量配置必须同时给出：

- 必经战、可选战、目标战的不同计数，以及玩家绕行后的最少／最多战数。
- 可领取的事件与奖励上限，而不仅是地图上有多少个标记。
- 不依赖随机事件抽中的基础补给机会；通向它的路径不能强制先打可选精英。
- 携行容量、技能剩余次数、侵蚀与恢复的耗损账，区分最低投入和追求清图的行为。
- 目标可达、主动返程和中途放弃的情况；不以玩家按预定顺序探索为前提。

未完成这些数值前，不能用旧短途预算生成一张塞满内容的大图，也不能宣传确定的时长或胜率。灰栎样图02已调整跨区出口，下一步先验证跨区路线与资源预算，比较直奔目标、先找补给、绕行和回头探索四类路线；这些是验证场景，不是玩家行为预测。

## 奖励配置

基础补给、事件收获、战斗奖和探索物资分别登记来源，并共用明确的整趟预算。补给可以是消耗携行物的整备服务、原配方制作或限量物资点；只有前两种服务而没有足够材料时，不能声称恢复已经有保障。新增免费物资必须单列数量与领取次数，不能把安全营地写成无限恢复。

地图上可见的营地与工作台数量不等于事件数，也不自动占奖励额度；是否提供有奖励的一次交互，在出发配置中声明。清空可选据点有收益但不是主线的必选步骤；普通回访不生怪、不重置库存、不返还已用材料额度。即使允许回头清图，行走本身也不新增行动日或隐形耗损。

## 数据归属、迁移与验收

本专项与[连续地图合同](../校验/连续区域地图合同.json)是MAP-CONT-1.0空间组织的权威补充。七份TINDER-1.7主JSON保留为已校核的内容与短途基线；其中地图route_templates、固定7层与常规2—3战约束，事件trigger.layers及旧两事件上限，不再直接约束新的常规连续地图。章节、地区、人物结局、战斗公式、装备配方、真实教学与回执仍沿原源文件。不是笼统地以新文件覆盖所有字段。

新生成器须显式选择MULTI-1.1的SHORT／MEDIUM／LONG，或独立固定任务配置；原LEGACY_SHORT不再是普通短途。连续配置缺少数值、地点绑定或预算时，出发前报告配置不完整，不偷偷回退成七层路线。旧存档按已保存布局继续，不中途转换；教程、救援及终局固定专线维持自身规则。

| 验收对象 | 可判断的标准 |
| --- | --- |
| 连续探索 | 从入口到目标再回入口全程实际走路，无逐节点传送；普通岔路允许返回 |
| 原地接敌 | 战前、战中、战后使用同一地点与地形；已看见的敌人身份不变 |
| 多遭遇分布 | 独立敌群不会误合并；可绕过敌群不被计作已打赢 |
| 事件落地 | 每张投放卡有真实对象及必要服务；缺服务时剔除；看见不等于确认 |
| 补给可达 | 基础补给机会可达且规则可读；领取后回访不能刷新；实际供需另测 |
| 空间与预算 | 放入图中的每场可打战斗、每份可领收益都有所属额度；替代版不重复结算 |
| 存续与风险 | 回访、点灯、读档不重新生成；地段暴露与战果分别去重 |
| 主线独立性 | 跳过随机事件或可选据点不造成主目标不可达，不伪造保全与觉醒 |

本次交付是地图规则修订，没有制作场景或验证引擎寻路。原静态报告只证明其输入版本的合同，不能代替上表的空间体验验收。
