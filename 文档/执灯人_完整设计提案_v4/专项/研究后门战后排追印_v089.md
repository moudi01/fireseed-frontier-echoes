# 研究后普通门战：无弹道后排追印（0.89）

2026-11-01。用于第三章中途的双线压力，与已有后阵校准体的锁地圈配合。

## 适用与配置

- 仅研究交付后的第三章普通远征（`CH3_COMPLETE`）、L5及以上的G门战。
- 从原敌阵选择最多一名既有远程敌人追加技能，优先EN22、其次EN11，再按公开固定种类及实例ID选取；不读取玩家阵容或职能。
- 原敌人数、站位、面板、原技能、预留兵力和奖励保持；新增校准体不兼任追印宿主。没有合适宿主时不额外补兵。
- 旧章、固定Boss与终局准备后的最高档门战沿用各自规则。

## 后阵追印

技能ID `C3-REAR-LOCK`，无弹道直接攻击，继承施术者原普攻的物理／魔法伤害类型及对应攻击力。

| 项目 | 规则 |
| --- | --- |
| 起手目标 | 6格射程且地形视线可达的最远站立人类；同距按实例ID稳定选择 |
| 排除 | 倒地者、伴兽、场景机制及Boss部位 |
| 预警与循环 | 起手3拍，释放后冷却5拍；最早第4拍可起手，按冷却循环 |
| 伤害 | 单体，对应攻击力×1.8，沿正常伤害结算 |
| 锁定方式 | 起手附着到原目标本人，公开目标ID与释放拍；不锁地面格 |
| 释放 | 原目标仍站立时直接结算；换格、离开起手射程、进入遮挡后仍被追踪；目标倒地则落空，不改选他人 |
| 应对 | 起手前利用射程、地形与站位限制锁定；起手后可打断或合法延后，护盾、减伤及正常护卫代受有效 |

普通避险不会为了该技能消耗一次无效的侧移；已有锁地圈仍按自己的预警和避险规则处理。两种威胁分别由敌人正常行动时钟调度，不额外赠送攻击拍。

## 公开与保存

战前敌情公开目标规则、起手射程、预警、冷却、伤害和应对。战中状态显示锁定本人及释放拍，棋盘在被锁角色当前位置显示追印标记。锁定ID、到期拍与原动作随正常存档保存重载。

对应代码为灰盒的`late_pressure.py`、`spatial_moves.py`与`enemy_intel.py`；战斗创建白名单和状态显示由`combat.py`／`engine.py`接线。0.88原运行与存档保留；结清城镇通过明确升级入口另存为0.89，不回写旧战报。
