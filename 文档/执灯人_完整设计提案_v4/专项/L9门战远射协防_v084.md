# L9门战远射协防

2026-10-31，TINDER-GREYBOX-0.84。

最高档毕业奶盾队在原L9防守阵中只受少量持续攻击，治疗和汲生容易填平伤害。此次补敌阵的远射压力，保留原怪物面板、玩家奶盾按冷却无限使用及汲生规则。

仅普通远征、第三章、D2、出发已有FINALE_READY、有效威胁L9及以上的G门战启用。规则随出发公开冻结；低档、前中期、L8、非门战、救援／教学／固定拜访／终战保持原内容。

1. 统计原阵与召唤预留中的远射单位：普攻射程至少3，或有射程至少3的直接伤害主动。
2. 不足2名时，在棋盘左右前侧合法空格补骷髅弓手，最多补2名，原敌人保留。初始单位与召唤预留合计最多6名；避开机制对象、召唤候选和原单位占位。
3. 协防弓手使用既有EN22模板和L9成长。穿阵骨箭W2／C6循环、最多2目标，锁线不追踪，可走位规避、打断；原EN22模板的技能次数不改。
4. 每名协防计入2点敌阵威胁预算；战前敌情公开实际人数、位置、面板和技能。没有按玩家队伍强弱增减敌人，不新增路线抽样或掉落次数。

该规则让防守型门战也需要处理侧翼射线和持续攻击，形成保留治疗与加速清敌的取舍。原断阵重击仍只有一次起手，内圈留人触发外圈，真实重创和主动撤退规则沿用。
