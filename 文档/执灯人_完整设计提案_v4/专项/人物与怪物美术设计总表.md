# 《火种计划：边境回响》人物与怪物美术设计总表

整理日期：2026-11-12。**一行对应一个现行人物、兵种／职业、物种或需单独辨认的实体**；同一职业可招募多个独立的人，此表登记的是可复用造型族，不把每个随机实例误算成新角色。**作者确认：S01–S03 士兵每类制作男、女两版；M01–M08 佣兵每个职业只设计一种性别造型。**职业装备、动作功能和阵营识别须保持清楚。表中“识别重点”从现行叙事、战斗功能和已有角色造型要求提取，供下一步美术设计使用，**不是已完成的模型验收**。旧 Godot 暖色远征样机可作风格参考，但火种计划当前以 Python 灰盒为主，不能把旧样机的资产完成状态直接继承到本表。
