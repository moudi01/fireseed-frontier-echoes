# 贯阵约定实战调整（0.82）

2026-10-31。运行增补；原0.66／0.81资料按历史理解。实际结果见[0.82验证记录](../../../原型/火种计划_远征灰盒/验证记录_v082.md)，任务状态以[唯一路线图](../../../开发总路线图_执行版.md)为准。

旧规则在普通战场经常没有同轴第二敌，却对每次近击普攻增加1拍间隔。本次保留近击群伤定位，改为主目标周围的有限波及，并只在存在合法额外目标时付出间隔代价。

| 条目 | 普通F09 | 稀有R09 |
| --- | --- | --- |
| 起始动作 | 玩家原始近击BASIC | 同左 |
| 波及范围 | 主目标周围2格 | 主目标周围3格 |
| 附带人数 | 最多1个额外独立生命 | 最多2个额外独立生命 |
| 伤害系数 | 每个0.6 | 同左 |
| 间隔 | 有合法额外目标，本次+1拍；否则基础间隔 | 同左，多目标不重复加价 |

原目标须在原攻击范围内；额外目标可超出本人普攻范围，但施术者与主目标都须能看见它。高障碍、友军、死亡或未入场者不构成额外目标。按距主目标、距施术者、ID稳定排序；原生范围已覆盖的目标不占附带名额，同Boss本体及部位不重复。

在释放选目标后，以本动作起手时的基础ready加1作为下限，不在当前timer上重复累加。合法额外目标的盾吸收或闪避不退款；“没有额外入血”与“没有额外目标”不同。H10原生扇形保留原目标和1.4／1／1系数；技能、书主动、指挥响应及刺客专属连锁不因此改造，也不制造额外普攻。

F09／R09的抽取ID、池、概率、4铜与2材料领取额度费用保持；持续本趟、同fortune整组替换／清除、归城到期保持。旧档仍须使用对应旧入口，不迁来源戳。

选择建议依据机制而非强制必选：适合有近击普攻、敌人能够进入同一可见区域的队伍；群伤会降低原目标的连续击杀节奏。实测同源士兵队虽更快结束战斗，前排却更早倒地，末态HP也更低。原生技能已占满行动的英雄仍不会因此多出普攻。固定作者样本不证明全部流派或最深关卡平衡。
