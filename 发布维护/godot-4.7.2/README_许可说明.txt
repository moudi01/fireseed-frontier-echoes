P06 Windows 随包许可说明

P06.exe 使用 Godot 4.7.2 官方 Windows x86_64 发布模板，游戏 PCK 嵌入该可执行文件。
以下文件可直接用文本编辑器打开：

  licenses/godot-4.7.2/LICENSE.txt
    Godot 引擎完整许可。
  licenses/godot-4.7.2/COPYRIGHT.json
    引擎内置组件、源文件范围、版权持有人与许可对应表。
  licenses/godot-4.7.2/THIRD_PARTY_LICENSES.txt
    引擎提供的完整第三方许可正文，按许可名称分节。
  licenses/godot-4.7.2/provenance.json
    版本、来源与声明文件校验信息。
  sidecar/runtime/LICENSE.txt
    随包 Python 运行时的许可说明。
  licenses/p06-windows-license-manifest.json
    本包可执行文件、嵌入 PCK 与 Python 许可的校验记录。

Godot 声明取自项目已核对的官方 4.7.2 编辑器及 Windows 模板内置许可 API。
官方参考：https://docs.godotengine.org/en/4.7/about/complying_with_licenses.html

模型、贴图、动画、音频及其他项目素材的来源与历史授权由项目单独核查。
本说明的随包存在不构成对外分发批准。
